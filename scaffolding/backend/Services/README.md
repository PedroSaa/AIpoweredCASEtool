# Servicios

Esta carpeta contiene los servicios generados por AICASE.

Cada entidad genera:
- `I{Entidad}Service.cs` - Interfaz del servicio
- `{Entidad}Service.cs` - Implementación con reglas de negocio

Los servicios contienen la lógica de negocio definida en el JSON maestro.
Las reglas complejas son implementadas con ayuda de IA.
